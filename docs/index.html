About the analysis

This dashboard estimates physical on-site electricity coverage using real hourly wind data and a calibrated synthetic industrial demand profile.

◌

Method

The hourly demand profile is synthetic because public hourly consumption is not available, but its annual total is calibrated to Aalborg Portland's reported electricity consumption.

Data product

The page is generated automatically from pipeline outputs and published as a static GitHub Pages dashboard.
